# Hava Durumu

Şehir arayarak anlık hava durumunu ve 7 günlük tahmini gösteren basit web uygulaması.

## 🌐 Canlı Demo

**[cumalibilgic.github.io/hava-durumu](https://cumalibilgic.github.io/hava-durumu/)**

Bağlantıya tıklayarak uygulamayı doğrudan tarayıcında açabilirsin, kurulum gerekmez.

## Özellikler

- Şehir arama
- Anlık hava durumu
- 7 günlük tahmin

## Kullanılan teknolojiler

- HTML, CSS ve JavaScript (tek dosya: `index.html`)
- [Open-Meteo](https://open-meteo.com/) hava durumu ve geocoding API'leri (API anahtarı gerektirmez)

## Yerelde çalıştırma

```bash
git clone https://github.com/cumalibilgic/hava-durumu.git
cd hava-durumu
```

Ardından `index.html` dosyasını tarayıcıda aç.
